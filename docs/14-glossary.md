# 14 — Glossary

| Term | Meaning in this project |
|---|---|
| **ADC** | Analog-to-digital converter. The ATmega328P has a 10-bit ADC (0–1023) read by `analogRead`. |
| **ADR** | Architecture Decision Record: a short document in `docs/adr/` recording one decision, its alternatives and consequences. |
| **Arena** | A physics environment (line track, maze, sumo ring…) where robots are tested. |
| **ArticulationBody** | Unity's reduced-coordinate physics body for jointed chains (robot arms, wheeled bases); more stable than joint constraints between rigid bodies. |
| **AVR / AVRe+** | Microchip (formerly Atmel) 8-bit microcontroller architecture; the ATmega328P (Uno/Nano) and ATmega2560 (Mega) are AVR chips. |
| **Back-EMF** | Voltage generated by a spinning motor that opposes the supply; it is why motor current falls as speed rises. |
| **Baud** | Serial bit rate. Uno sketches commonly use 9600 or 115200. |
| **Behaviour model** | The C# class that gives a component its dynamics (motor, sensor timing, servo), as opposed to its electrical model. |
| **Binary-level emulation** | Executing the compiled machine code (`.hex`) instruction by instruction, as opposed to interpreting the C++ source. |
| **BOD / brown-out** | Brown-out detection: the MCU resets itself when VCC drops below a fuse-selected level (2.7 V on the Uno). |
| **Body Studio** | The in-app 3D body designer (doc 08). |
| **Breadboard tie-point** | One hole in a breadboard; groups of five are connected internally in a terminal strip. |
| **CSG / boolean** | Constructive solid geometry: union, difference and intersection of solids; implemented with Manifold. |
| **Cycle-accurate** | Every instruction and peripheral event is accounted at the level of the 16 MHz clock cycle (62.5 ns). |
| **Decay mode (slow/fast)** | How an H-bridge lets motor current decay during the PWM off-time; affects average voltage and braking. |
| **DLC / pack** | Downloadable content on Steam. Here every paid pack (board, part or customization pack) is a DLC that works as an ownership flag; the content itself is already installed. |
| **Cosmetic / finish** | A purely visual change (texture, decal, skin). Never changes physics or electrical behaviour. |
| **Entitlement** | Whether the player owns a pack; checked by the app, never by the simulation core. |
| **F2P** | Free to play: the base game is free and optional packs are paid (ADR-0007). |
| **Try mode** | Using a paid part or finish without owning it: simulation works, saving/exporting that project does not. |
| **Determinism** | Same inputs produce the same simulation, enabling replays and automated tests. |
| **Dupont / jumper wire** | Pre-made wire with male (M) or female (F) pin ends; M-M, M-F, F-F. |
| **EA** | Early Access on Steam. Not used: the game ships as one full release (ADR-0008). |
| **Electrical model** | The part of a component that participates in the net solver (resistances, sources, thresholds), doc 06. |
| **Emulator vs simulator** | Emulator: reproduces the chip's behaviour so unmodified binaries run. Simulator: reproduces observable behaviour by any means (our physics and electrical layers are simulators). |
| **FQBN** | Fully Qualified Board Name for arduino-cli, e.g. `arduino:avr:uno`. |
| **Floating input** | An input pin connected to nothing; it reads random values. Fixed by pull-up/pull-down resistors or `INPUT_PULLUP`. |
| **H-bridge** | Four-switch circuit (L298N, TB6612) that drives a DC motor in both directions. |
| **HEX / Intel HEX** | Text format of the compiled program that is flashed to the MCU; our emulator loads it directly. |
| **I2C / TWI** | Two-wire bus (SDA/SCL) used by displays and IMUs; needs pull-up resistors; A4/A5 on the Uno. |
| **IL2CPP** | Unity's ahead-of-time C# to C++ compiler used for release builds. |
| **kg·cm** | Torque unit used in hobby motor datasheets (1 kg·cm ≈ 0.098 N·m). |
| **LDO / dropout** | Low-dropout linear regulator; needs an input a bit higher than its output (NCP1117: ≈ 1.1–1.2 V). |
| **Lockstep** | All simulation parts advance by the same fixed time step in a fixed order. |
| **Manifold (mesh)** | A watertight mesh with consistent topology; required for reliable booleans and 3D printing. |
| **MNA** | Modified Nodal Analysis: the matrix method used to solve node voltages in the analog solver. |
| **MoR** | Merchant of record (Paddle, FastSpring): handles VAT and payments for direct sales. |
| **Net / netlist** | A set of electrically connected pins; the netlist is all nets of a project. |
| **Notebook** | The in-game reference: datasheet cards, error help, "why it broke" cards, event log. |
| **Polyfuse** | Resettable fuse on the Uno's USB input (trips above 500 mA and recovers). |
| **Pull-up / pull-down** | Resistor holding an input at a defined level when nothing drives it. |
| **PWM / duty cycle** | Pulse-width modulation; `analogWrite(0–255)` sets the fraction of time the pin is high (490/980 Hz on the Uno). |
| **Sandbox** | The whole game: free building and testing with no goals set by the game (ADR-0008). |
| **Sketch / .ino** | An Arduino program; the main file has the `.ino` extension. |
| **SPI** | Serial peripheral interface (SCK/MOSI/MISO) on pins 13/11/12 of the Uno. |
| **Stall current** | Current a motor draws when it cannot turn; the maximum for that voltage. |
| **STEAM vs Steam** | STEAM: science, technology, engineering, arts, mathematics education. Steam: Valve's store. |
| **SteamPipe** | Valve's build upload system (`steamcmd`, depots). |
| **STL** | Mesh file format used for 3D printing; our export format. |
| **Tutorial** | The 5–10 minute interactive introduction to the controls (doc 10 §3). |
| **UART / USART** | Serial port hardware; the Uno has one, on pins 0/1, shared with the USB bridge. |
| **USB bridge** | The ATmega16U2 (Uno) or CH340 (Nano clones) chip that converts USB to serial and performs auto-reset. |
| **Vertical slice** | A small but complete version of the product across all pillars (Phase 1 in doc 11). |
| **Workbench** | The main 3D scene where building and wiring happen. |
| **Workshop** | Steam Workshop: user-generated content sharing. |
